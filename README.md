# BotaniBowl (揀飲擇植)

A swiping game about nutrition and environmental budgets.

Build a meal that meets a customer's nutrition targets without exceeding a water or land budget. The food data comes from OWID and the Hong Kong CFS. The customer is a cartoon; the numbers are not.
